# CMC-TEI-Encoding-Examples
Sample CMC documents annotated according to the TEI Guidelines Chapter 9 _Computer-mediated communication_

The same primary sample data as provided for cmc-core in the older cmc-core repo below, but re-annotated according the new (as of 2024) chapter 9 in the TEI guidelines

1. 2nd Life sample from the project [CoMeRe](https://repository.ortolang.fr/api/content/comere/v2/comere.html)
2. Internet relay chat from the Dortmund chat corpus
3. Two samples of whatsApp private chat from the Mobile Communication Database (MoCoDa2) corpus
4. A twitter sample
5. A wikipedia talk page
